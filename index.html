LinkedIn Post Analytics

Privacy Policy

Effective date: October 21, 2026

Overview

Your analytics stay in your browser. The extension has no developer-operated analytics server and does not sell your data.

This policy explains how the LinkedIn Post Analytics Chrome extension processes information when you use it.

Information the extension processes

When you choose to scan LinkedIn, the extension may read information visible on the LinkedIn page in your active tab, including:

  • Post text, post URL, author name, media type, and publication date.
  • Visible engagement counts such as reactions, comments, and reposts.
  • Visible names and profile links shown in reaction or comment details.
  • Scan timestamps and metric snapshots used to calculate changes over time.

If you add a Gemini API key, the extension also stores that key locally in Chrome.

How information is used

The extension uses this information only to provide the features you request: build the analytics dashboard, calculate engagement and trends, filter or compare posts, import or export your records, and optionally classify post topics with Gemini.

Information is not used for advertising, credit decisions, or sale to third parties.

Local storage and retention

Collected post records and the Gemini API key are stored in chrome.storage.local on your device. The API key is stored separately and is excluded from CSV and JSON exports.

Records remain until you clear them in the extension, remove the extension and its local data, or replace them through an import. You can remove the Gemini key at any time from Settings.

Gemini and third-party sharing

Topic analysis is optional and runs only after you add your own Gemini API key and select the analysis action. For that feature, the extension sends the relevant post text and media type directly to the Google Gemini API over HTTPS. Your API key is sent to Google only to authenticate that request.

Google processes that request under its own terms and privacy practices. Review the Gemini API terms and Google Privacy Policy.

No scanned LinkedIn data or Gemini key is sent to the extension developer.

Your choices and controls

  • Scanning starts only when you choose a scan action.
  • Gemini analysis is optional and requires your own key.
  • You can export your saved post records as CSV or JSON.
  • You can clear all saved post data or remove the Gemini key from Settings.

Security

The extension limits processing to the permissions and actions needed for its features and uses HTTPS for Gemini requests. No storage or transmission method can be guaranteed completely secure, so use an API key restricted to the Gemini API where available and keep your browser and extension updated.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Children’s privacy

The extension is not directed to children under 13 and does not knowingly collect personal information from children.

Changes to this policy

This policy may be updated when the extension’s data practices or features change. The effective date at the top of this page will be revised when an update is published.

Contact

For privacy questions or support, open an issue in the project’s GitHub repository.

Independent extension

LinkedIn Post Analytics is an independent project and is not affiliated with, endorsed by, or sponsored by LinkedIn or Google.
